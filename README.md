 # 🎯 나만의 CS & Python 퀴즈 게임
 
-터미널 환경에서 실행되는 4지선다형 파이썬 퀴즈 콘솔 프로그램입니다.  
-`state.json` 파일을 활용하여 퀴즈 목록과 최고 점수를 안전하게 보존합니다.
+## 프로젝트 개요
+터미널에서 `main.py`로 실행되는 4지선다형 Python 콘솔 퀴즈 게임입니다. 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 확인, 최고 점수 확인, 종료를 선택할 수 있습니다. 프로그램은 프로젝트 루트의 `state.json` 파일을 UTF-8 JSON으로 저장하고 불러와서 프로그램을 종료한 뒤 다시 실행해도 추가한 퀴즈와 최고 점수가 유지됩니다.

+## 기능 목록
+1. **퀴즈 풀기**
+   - 저장된 모든 퀴즈를 순서대로 출제합니다.
+   - 정답 입력은 1~4 사이 숫자만 허용합니다.
+   - 모든 문제 풀이 후 정답 수와 100점 환산 점수를 출력합니다.
+   - 기존 최고 점수보다 높으면 최고 점수를 갱신하고 저장합니다.
+2. **퀴즈 추가**
+   - 문제, 선택지 4개, 정답 번호를 입력받습니다.
+   - 추가한 퀴즈는 즉시 `state.json`에 저장됩니다.
+3. **퀴즈 목록**
+   - 등록된 퀴즈 질문 목록과 총 개수를 출력합니다.
+4. **점수 확인**
+   - 아직 퀴즈를 풀지 않았으면 안내 메시지를 출력합니다.
+   - 최고 점수가 있으면 점수를 출력합니다.
+5. **안전한 입력/예외 처리**
+   - 숫자 입력의 앞뒤 공백을 제거합니다.
+   - 빈 입력, 숫자가 아닌 입력, 범위 밖 숫자를 안내하고 다시 입력받습니다.
+   - `Ctrl+C` 또는 입력 스트림 종료가 발생하면 가능한 범위에서 데이터를 저장하고 안전하게 종료합니다.
+   - `state.json`이 없거나 손상된 경우 기본 퀴즈 데이터로 실행 및 복구합니다.
+

+## 데이터 파일 설명: `state.json`
+- **경로**: 프로젝트 루트의 `state.json`
+- **역할**: 퀴즈 목록과 최고 점수를 저장하여 프로그램 재실행 후에도 데이터를 유지합니다.
+- **인코딩**: UTF-8
+- **Git 관리**: 개인 실행 데이터이므로 `.gitignore`에 포함되어 저장소에는 커밋하지 않습니다.
+
+### 스키마 예시
+```json
+{
+    "quizzes": [
+        {
+            "question": "파이썬(Python)의 창시자는 누구일까요?",
+            "choices": [
+                "Guido van Rossum",
+                "Linus Torvalds",
+                "James Gosling",
+                "Bjarne Stroustrup"
+            ],
+            "answer": 1
+        }
+    ],
+    "best_score": 80
+}
+```
+
+| 필드 | 타입 | 설명 |
+| --- | --- | --- |
+| `quizzes` | list | 저장된 퀴즈 목록 |
+| `question` | str | 문제 문장 |
+| `choices` | list[str] | 4개의 선택지 |
+| `answer` | int | 정답 번호, 1~4 |
+| `best_score` | int 또는 null | 최고 점수. 아직 풀이 기록이 없으면 `null` |
+
