# 🎯 나만의 파이썬 퀴즈 게임

터미널에서 실행하는 4지선다형 파이썬 퀴즈 게임입니다.
사용자는 퀴즈를 풀고, 새 퀴즈를 추가하고, 퀴즈 목록과 최고 점수를 확인할 수 있습니다.

## 📌 프로젝트 주제

- **주제**: Python 기본 문법 퀴즈
- **내용**: 리스트 메서드, 주석, 딕셔너리, 예외 처리, 함수 반환 키워드 등
- **목표**: 파이썬 기초 개념을 퀴즈 게임으로 복습하기

## 📁 파일 구성

```text
quiz-game/
├── main.py        # 프로그램 실행 파일
├── quiz.py        # Quiz 클래스와 기본 파이썬 퀴즈 데이터
├── quiz_game.py   # 게임 메뉴, 퀴즈 진행, 저장/불러오기 관리
├── state.json     # 퀴즈 데이터와 최고 점수 저장 파일
├── mission_2.md   # 미션 설명 파일
└── README.md      # 프로젝트 설명 파일
